## Preparation checklist

- [ ] Read the individual pattern's development and delivery notes
- [ ] Obtain the actual pattern and complete instructions
- [ ] Record current measurements and choose the size from the prepared guide
- [ ] Confirm fabric type, quantities and notions
- [ ] Prepare fabric according to the appropriate care instructions
- [ ] Measure the PDF test reference in both directions
- [ ] Print the selected size and page range
- [ ] Assemble sheets and inspect joins and marks
- [ ] Confirm seam allowances and cutting quantities
- [ ] Make and assess a fitting sample where needed
- [ ] Update the plan before cutting final fabric
