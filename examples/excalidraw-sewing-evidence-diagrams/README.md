# Sewlore Sewing Evidence Diagrams

Eight original editable library groups for grain direction, placing an edge on fold, notch matching, cutting versus seam lines, button-centre registration, independent width/height, paired care readings and PDF tile registration.

## Files and import

- `sewlore-sewing-evidence-diagrams.excalidrawlib`: native Excalidraw library version 2 with eight groups and 54 editable vector/text elements.
- `library-preview.excalidraw`: editable native scene containing all eight groups.
- `library-preview.png`: offline rendering of those same primitives.

Open Excalidraw's library panel and import the `.excalidrawlib` file. The scene can be opened independently for inspection. Structural JSON checks, unique IDs, finite geometry and grouped editable primitives were checked. **Native editor import and library-directory acceptance remain unverified.** The PNG is not a fabricated native editor screenshot.

These schematic diagrams are not calibrated rulers, prescribed seam allowances, tested garment patterns or measurements from a physical specimen. Follow the pattern designer's legend and instructions. Original AI-assisted procedural assets were created afresh for this library; no prior CC BY Penpot files or third-party icons were reused.
