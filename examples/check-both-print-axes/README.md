# Check Both Axes Before Printing a Sewing Pattern

[Download the 12-slide presentation](Sewlore-Check-Both-Axes.pdf).

This Sewlore guide explains how to check a PDF sewing pattern's reference square before printing the remaining pages. It covers separate width and height calculations, A4 and US Letter paper formats, and a workflow for measuring and retesting the actual sheet.

## Digital example inputs

Each example starts with an intended 100 mm by 100 mm square. The presentation tables use the following rounded digital path dimensions:

| Example | Width | Height | Width scale | Height scale |
| --- | ---: | ---: | ---: | ---: |
| Untransformed reference | 100 mm | 100 mm | 100% | 100% |
| Uniform 0.95 transformation | 95 mm | 95 mm | 95% | 95% |
| Unequal 0.96 / 1.04 transformation | 96 mm | 104 mm | 96% | 104% |

Scale is measured dimension divided by intended dimension, multiplied by 100. The average of 96% and 104% is 100%, but neither axis has the intended length. A uniform adjustment that brings 96 mm to 100 mm would bring 104 mm to about 108.33 mm.

The examples and illustrations come from Sewlore's [PDF geometry test kit](https://gokimedia.github.io/sewlore-sewing-tools/docs/pdf-print-geometry-atlas/): generated reference PDFs, known programmatic transformations and extracted vector path dimensions. These are digital controls, not physical printer tests. Original labels remain unchanged in the transformed illustrations; slide images are not rulers.

## Use with an actual pattern

Follow the pattern publisher's printing instructions, reference marks and stated tolerance. Print one test page, measure both axes on the actual sheet, and inspect clipping and registration marks. A correctly measured square alone does not establish complete pages or garment fit.

Read the [Sewlore printing and assembly guide](https://sewlore.com/pages/printing-assembly) for the preparation workflow.
