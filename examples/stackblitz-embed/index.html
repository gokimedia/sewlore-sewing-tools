Sewlore · Developer example

Two tools. A few lines of HTML.

Add a fabric stretch calculator or a PDF print scale checker to a sewing resource page. These examples load the live tools from Hugging Face; the calculations stay inside each embedded app.

The tool parameter selects the opening tab. Both tool tabs remain available in each frame.

Example 01

Fabric Stretch Lab

Record relaxed, stretched and released lengths. The tool calculates stretch percentage and records the change after release.

Frame unavailable? Open the fabric stretch calculator (new tab).

Before you embed

Choose the context, keep the fallback.

Use one tool frame per resource page when that is enough. Adjust its height to suit your layout, retain a descriptive title, and keep a visible link to the corresponding Sewlore page for visitors whose browser blocks the frame.

The frames scroll independently. This example does not read their inputs or send measurement data between the parent page and the tools.

Measurement privacy

The tool app calculates in the visitor's browser and does not upload entered measurements or add analytics. This starter adds no analytics, cookies or measurement collection. Hugging Face and the site hosting this example still receive normal web requests, such as the request to load a page or file. If opened in StackBlitz, that platform also receives the requests needed for its editor and preview.

Source attribution is optional

These snippets intentionally omit source. Leave it out when embedding on Sewlore so navigation within the site is not labelled as a referral.

A partner may opt into attribution by adding &source=partner_name to the iframe URL. It tags outbound Sewlore links; it does not submit measurements. Replace partner_name with an agreed source value, and keep it out of the default embed unless the partner chooses it.
