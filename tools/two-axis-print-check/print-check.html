Check both directions of a PDF print

Measure the complete reference rectangle supplied with your pattern. Enter its intended width and height, then the dimensions on the printed test page.

All four measurements must use the same unit. A single point or comma is read as a decimal separator: write 1000 for one thousand, not 1,000. The calculator compares your entries locally in this tab.

Choose the unit before entering values. Changing this selection does not convert the numbers.

A negative error means that direction printed smaller; a positive error means it printed larger. Results are displayed to eight significant digits. No pass/fail tolerance is assumed.

Formulas and what to check next

For each direction separately:

  • Scale (%) = measured ÷ intended × 100.
  • Signed error (%) = (measured − intended) ÷ intended × 100.
  • Length difference = measured − intended, in the selected unit.

The absolute difference between the two signed errors is reported in percentage points. It describes the entries; it does not establish a printer accuracy threshold.

Follow the pattern publisher's printing instructions and tolerance, check the paper size and driver settings, and print another test page after changing a setting. An unequal change in width and height cannot be corrected exactly by one uniform scale percentage.

This tool does not modify a PDF, recommend a correction percentage, inspect clipping or page assembly, or establish garment fit. Screen rulers, browser zoom and this page's layout are not physical calibration references.
