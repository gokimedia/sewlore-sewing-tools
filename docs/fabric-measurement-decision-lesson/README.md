# Choose the Right Fabric Measurement | Sewlore

An original interactive lesson with three routes and nine decisions about comparable readings, stretch and recovery denominators, signed care change and rectangular area. Corrective explanations return the learner to the relevant decision. The activity is ungraded and learner-paced.

- [Open the accessible browser lesson](index.html).
- [Download the H5P Branching Scenario](sewlore-choose-right-fabric-measurement.h5p) for a compatible H5P player.
- [Read the Sewlore methods guide](https://sewlore.com/pages/fabric-measurement-methods-guide) for formulas, recording context, input policy and source references.

All numbers are invented arithmetic examples. No fabric specimen test, textile certification, garment-fit prediction or physical printing result is claimed.
